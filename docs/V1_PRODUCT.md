# QA Gatekeeper v1.0 Product Specification

## Workbench

Cross-Track QA Queue

## Domain table

QA findings

## Metrics

- Pass/Fail Gate
- Severity Load
- Evidence Coverage

## Domain rows

- Deliverable links entered
- Track template selected
- Reviewer assigned
- Defects logged
- Severity assigned
- Evidence attached
- Acceptance criteria checked
- QA certificate exported

## Generated deliverables

- QA certificate
- Defect log
- Client acceptance checklist

## Validation gates

- Critical defects block approval
- Evidence required for ready
- Mentor and owner approvals required
